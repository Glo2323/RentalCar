Rental Car Calculator – Java Console Application
This project is a simple Java console application that calculates the estimated cost of renting a car based on user-selected options. It was created as part of a programming exercise focused on input handling, conditional logic, and basic arithmetic operations.

📌 Features
The application prompts the user for:

Pickup date

Number of rental days

Electronic toll tag option ($3.95/day)

GPS option ($2.95/day)

Roadside assistance option ($3.95/day)

Driver age

Using this information, it calculates:

Basic rental cost ($29.99/day)

Options cost (based on selected add-ons)

Underage surcharge (30% of basic rental for drivers under 25)

Total rental cost
